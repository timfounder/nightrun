# Assets

Сюда положи статичные файлы:

- `runner.jpg` — фото для hero (опционально). Подключение в `js/app.js` через `HERO_PHOTO_URL`
- `og.jpg` — баннер 1200×630 для превью при шеринге в соцсетях
- `favicon.svg` или `favicon.ico` — иконка вкладки браузера
- `apple-touch-icon.png` 180×180 — иконка для iOS при добавлении на главный экран

## Где взять бесплатные фото

- [Unsplash](https://unsplash.com) — поиск "night running", "city night", "running silhouette"
- [Pexels](https://pexels.com)
- [Pixabay](https://pixabay.com)

Все три источника — бесплатны для коммерческого использования, без обязательной атрибуции.

## Рекомендации к фото для hero

- Тёмный/ночной фон
- Силуэт бегуна или мотион-блюр
- Без яркой брендированной одежды
- Минимум 1500×1000px, лучше 2000px+
- Горизонтальная ориентация
